THE SOUTH AFRICA ATLAS OF GEOLOGICAL SITES — INTERACTIVE VERSION 2

Open index.html in a browser, or publish the entire contents of this folder to a static host such as GitHub Pages.

NEW FEATURES
- Responsive full-screen map and site explorer
- Site-name and province search
- 13 category filters and live results list
- Click-to-focus results, hover site names
- Redesigned popups with Google Earth, Wikipedia and verification links
- Layer toggles, reset extent, scale bar and About/Sources panel
- Original 40-site GeoJSON attributes preserved; no photos included

The generated qgis2web map, data, SVG symbols, CSS and JS assets must remain together.
If browser security prevents local file access, serve the folder with: python -m http.server 8000
Then visit http://localhost:8000/

Notes: This is a publication-ready candidate, not an independent geological accuracy audit. Check links and presentation in a browser before public release.
To change popup design, edit css/atlas-explorer.css and the pop_Geologicallandmark_5 function in index.html.
